강의 다시보기 서비스 제안서. 원본 PDF 7장을 스크롤 한 장짜리 웹페이지로 옮긴 것입니다.

**현재 상태: 시안 검토용.** 아직 채워야 할 곳이 남아 있습니다. 아래 "남은 작업"을 봐주세요.

## 열어보기

`index.html` 을 브라우저로 그냥 열면 됩니다. 빌드 과정도, 설치할 것도 없습니다.

GitHub Pages 로 올렸다면 주소는 이렇습니다:

```
https://<깃허브 아이디>.github.io/<저장소 이름>/
```

## 파일 구성

```
index.html      페이지 전부 (CSS·JS 안에 다 들어 있음)
img/            사진 16장
robots.txt      검색엔진 수집 차단 — 시안 단계라 막아둠
.nojekyll       GitHub Pages 가 Jekyll 로 재처리하지 않게
```

외부에서 불러오는 것은 글꼴 두 개뿐입니다. Pretendard(본문)와 Archivo(영문 표제).

## 남은 작업

| 항목 | 위치 | 상태 |
|---|---|---|
| Q&A 답변 8개 | `index.html` 의 `<span class="ph">답변을 넣어주세요</span>` | 질문만 있고 답이 없음 |
| 담당자 이름 | 최종 CTA 섹션 `[담당자 이름]` | 미정 |
| 전화번호 | 최종 CTA 섹션 `[전화번호]` | 미정 |
| 카카오톡 링크 | 최종 CTA 섹션 `[오픈채팅 또는 채널 링크]` | 미정 |
| 문의 버튼 연결 | `<script>` 안 `var CONTACT_URL = '';` | 이 한 줄만 채우면 버튼 전부 연결됨 |
| og:image 주소 | `<head>` 의 `og:image` | 배포 주소가 정해지면 전체 주소로 |

### 문의 버튼 연결하는 법

`index.html` 맨 아래 `<script>` 안에서 이 줄을 찾아 주소를 넣으면,
상단 네비 · 최종 CTA · 모바일 하단 고정 버튼이 한 번에 연결됩니다.

```js
var CONTACT_URL = '';   // 예: 'https://open.kakao.com/o/xxxxxxx'
```

## 확인이 필요한 것

- **단톡방 캡처에 실명이 보입니다** (`img/preview-kakao.jpg`, `img/step-5-upload.jpg`).
  하단에 `정영찬PD님`, 채팅방 이름 `원기T과학 투스카이 중3 통…`, 항목 `고등학교 1지망 희망조사`.
  본인 것이 아니면 가려야 합니다.
- **GitHub Pages 는 무료 계정에서 항상 공개됩니다.** 주소를 아는 사람은 누구나 볼 수 있습니다.
  단가표가 들어 있으니 검토가 끝나면 저장소를 비공개로 바꾸거나 Pages 를 끄는 편이 좋습니다.
  (`robots.txt` 로 검색 노출은 막아뒀지만, 주소를 직접 아는 접근은 막지 못합니다.)

3. `og:image` 를 전체 주소로 교체
