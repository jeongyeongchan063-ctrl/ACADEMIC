### 카카오톡 링크가 정해지면

최종 CTA 섹션(`id="contact"`)에 주석으로 감춰둔 줄이 있습니다.
`<!--` 와 `-->` 를 지우고 `[링크]` 자리에 주소를 넣으면 됩니다.

```html
<div class="cta-line">
  <span class="cta-k">카카오톡</span>
  <a class="cta-v cta-tel" href="[링크]" target="_blank" rel="noopener noreferrer">채널 바로가기</a>
</div>
```

대괄호 자리표시자가 그대로 보이면 미완성으로 읽히기 때문에 감춰뒀습니다.

### 문의 버튼

카카오톡 링크가 없는 동안에는 전화가 유일한 연락 수단이라,
최종 CTA 의 주 버튼을 `tel:` 로 연결해 두었습니다 (휴대폰에서 눌러서 바로 전화).
상단 네비와 모바일 하단 고정 버튼은 최종 CTA 섹션으로 이동합니다.

## 확인이 필요한 것

- **단톡방 캡처에 학원·학급 정보가 보입니다** (`img/preview-kakao.jpg`, `img/step-5-upload.jpg`).
  채팅방 이름 `원기T과학 투스카이 중3 통…` 과 항목 `고등학교 1지망 희망조사`.
  (`정영찬PD님` 은 담당자 본인이라 그대로 둡니다.)
  학원명·학급이 드러나도 괜찮은지만 확인하면 됩니다.
- **GitHub Pages 는 무료 계정에서 항상 공개됩니다.** 주소를 아는 사람은 누구나 볼 수 있습니다.
  단가표가 들어 있으니 검토가 끝나면 저장소를 비공개로 바꾸거나 Pages 를 끄는 편이 좋습니다.
  (`robots.txt` 로 검색 노출은 막아뒀지만, 주소를 직접 아는 접근은 막지 못합니다.)
